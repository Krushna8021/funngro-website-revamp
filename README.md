# Funngro Website Revamp — Two-page concept

This is an independent front-end concept created for a website development task. It is **not an official Funngro website** and does not collect or submit personal information.

## Files
- `index.html` — For Companies page
- `teen.html` — For Teens page
- `assets/styles.css` — responsive styling and shared visual system
- `assets/script.js` — mobile navigation interaction
- `SEO_AUDIT_REPORT.md` — initial audit/report and final testing checklist

## Run locally
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Recommended: install the VS Code **Live Server** extension.
4. Right-click `index.html` → **Open with Live Server**.
5. Test the Companies and Teens links and test at mobile and desktop widths.

You can also open `index.html` directly in a browser, but Live Server is preferable.

## Before publishing
1. Replace `https://YOUR-USERNAME.github.io/funngro-website-revamp/` in both HTML files with your actual deployed URL.
2. If you use a different host or repository name, update both canonical URLs and Open Graph URLs.
3. Confirm the final content and links; do not invent official statistics, endorsements or guarantees.
4. Publish both HTML files and the `assets` folder.
5. Test the public URLs in a private/incognito window.

## GitHub Pages deployment (simple route)
1. Sign in to GitHub and create a public repository named `funngro-website-revamp`.
2. Upload `index.html`, `teen.html`, and the complete `assets` folder (keep folder structure).
3. Open repository **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
5. Wait for GitHub Pages to publish the site. The URL will look like `https://YOUR-USERNAME.github.io/funngro-website-revamp/`.
6. Replace the placeholder canonical and Open Graph URLs in both HTML files with the actual URL, commit the change, and wait for redeployment.
7. Verify:
   - `https://YOUR-USERNAME.github.io/funngro-website-revamp/`
   - `https://YOUR-USERNAME.github.io/funngro-website-revamp/teen.html`
